Instrumentation

Analytics & Tracking

Every meaningful interaction is captured via PostHog for funnel analysis, drop-off detection, and engagement optimization.

📈 Funnel Events

  • onboarding_started Session begins
  • step1_completed Store info submitted
  • step2_completed Preferences saved
  • onboarding_completed Full flow finished
  • onboarding_abandoned User exits early

🔍 Engagement Events

  • step_viewed Step loaded with context
  • field_focused Form field interaction
  • store_type_selected Type chosen
  • map_interacted Map pan / zoom / click
  • insights_viewed Scroll depth tracked

📝 Captured Properties

  • store_type Selected store category
  • zip Retailer ZIP code
  • products_selected Category count
  • time_spent Seconds per step
  • contact_pref Text / email / phone
